## Deploy with Netlify

This is a source project, not a pre-built drag-and-drop `dist` folder.

1. Upload the project to GitHub.
2. Import the repository into Netlify.
3. Netlify can use the included `netlify.toml`.
4. The build output is `artifacts/prakruti-avenues/dist/public`.

The Vite configuration was also changed to use normal defaults for `PORT` and `BASE_PATH`, so it is less dependent on Replit-specific environment variables.

The production build has been verified locally with `pnpm --dir artifacts/prakruti-avenues run build`.
